Place the generated welcome MP3 files in this folder using these exact names:

welcome-id.mp3
welcome-en.mp3
welcome-de.mp3
welcome-ja.mp3

The landing page plays the file that matches the language selected in Classify.
Choose a natural female voice for each language in TTSMaker and preview it before
downloading. Keep each greeting short so it loads quickly.

Suggested scripts:

Indonesian: Selamat datang di Classify. Belajar jadi lebih terarah.
English: Welcome to Classify. A clearer way to learn, all in one place.
German: Willkommen bei Classify. Lernen an der Schule, klar und einfach an einem Ort.
Japanese: Classifyへようこそ。学校での学びを、もっとわかりやすく。
